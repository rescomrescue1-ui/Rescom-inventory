Res-Com Inventory & Truck Stock v1.0.0

Separate from Res-Com HVAC QR.
Airtable base: Res-Com Inventory & Truck Stock.
GitHub repository: Rescom-inventory.

Initial setup:
1. Upload entire ZIP contents to repository root.
2. Enable GitHub Pages from main branch / root.
3. Open the Pages URL online.
4. Connect the restricted Res-Com Airtable token on this device. Do not paste it into ChatGPT or GitHub.
5. Kai or Paul uses SET FIRST PIN with their existing developer email and chooses a 6-digit PIN.
6. Sign in and add trucks/items.

The repository/app is separate from the HVAC QR app and uses distinct local-storage keys and service-worker caches.
